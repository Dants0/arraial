# Contribuindo / Contributing

Obrigado por querer ajudar o Arraial! / Thanks for wanting to help Arraial!

## Relatar um problema / Reporting a bug
Abra uma *issue* com / Open an issue with:
- versões do Minecraft, Fabric Loader, Fabric API e Arraial / versions of Minecraft, Fabric Loader, Fabric API and Arraial;
- o que você fez, o que esperava e o que aconteceu / what you did, what you expected and what happened;
- o `latest.log` (pasta `logs`) ou o relatório de crash / your `latest.log` or crash report;
- se possível, uma captura de tela / a screenshot if you can.

## Sugestões / Suggestions
Ideias são bem-vindas como *issue*. O mod segue uma visão própria (vilas coloniais brasileiras que se governam sozinhas), então nem toda ideia entra, mas todas são lidas.
Ideas are welcome as issues. The mod follows its own vision, so not every idea gets in, but all are read.

## Pull requests
- Converse antes numa *issue* para mudanças grandes / Discuss big changes in an issue first.
- Compile com `./gradlew build` (Java 25) e teste em jogo / Build with `./gradlew build` (Java 25) and test in game.
- Textos novos vão em `pt_br.json` e `en_us.json` / New texts go in both `pt_br.json` and `en_us.json`.
- Texturas são geradas pelos scripts em `tools/` sempre que possível / Textures are generated by the scripts in `tools/` where possible.

**By contributing you agree to section 4 of the [LICENSE](LICENSE):** you confirm the work is yours and grant the author the right to use and distribute it as part of the mod. You will be credited.
