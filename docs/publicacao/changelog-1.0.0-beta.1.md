# Arraial 1.0.0-beta.1

First public release. / Primeira versão pública.

**Requires:** Minecraft 26.3, Fabric Loader 0.20.1+, Fabric API, Java 25. **Optional:** JEI.

- Founding with the Cruzeiro, 16 trades, construction projects, stages up to Cidade.
- Economy (réis, market, peddlers, orders, muleteers, contracts), politics (council, votes, taxes, coronéis).
- Living region: autonomous neighbours, migration, territory, disputes, war, the Chancery (treaties, tribute, embargo) and the Regional Map.
- Calendar and festas, crises, culture and traditions, personal lives, families and inheritance, ruins and bandits.
- Three eras of architecture with colonial blocks (taipa, telha, cal, azulejo).
- New villager skins, vaqueiro leather, tools, foods, 23 advancements, a 49-page in-game guide, JEI support.

⚠️ Beta: back up your worlds and report bugs at https://github.com/Dants0/arraial/issues
